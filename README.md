# Spree Internationalization (retired)

Spree 6.0 ships its translations as part of Spree itself, so this gem is no longer needed.

**Remove `spree_i18n` from your Gemfile.** Version 6.0.0 contains no translations and only prints a warning, so an app that still lists it keeps working.

To change a translation or add a language, see [Translations](https://spreecommerce.org/docs/developer/core-concepts/translations). Corrections to the translations Spree ships are welcome as pull requests to the [Spree repository](https://github.com/spree/spree/tree/main/spree/core/config/locales).

Spree 5 stores keep using `spree_i18n` 5.x.
